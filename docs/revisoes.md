# Registro de revisões

Cada conteúdo só passa a `status: aprovado` depois de aprovação **escrita** do responsável
pela área. Registre aqui quem aprovou, quando e qual versão do texto.

| Data | Conteúdo (tema ou categoria do quiz) | Área | Aprovado por | Versão aprovada | Observações |
|------|--------------------------------------|------|--------------|-----------------|-------------|
|      |                                      |      |              |                 |             |

Critérios para aprovar um tema:

1. Aprovação escrita do responsável da área.
2. Pelo menos uma referência confiável, com URL funcionando e data de acesso.
3. Sem linguagem de diagnóstico ou prescrição individualizada.
4. Linguagem simples, com termos técnicos explicados.
5. Imagens, se houver, com licença ou autorização e texto alternativo.
